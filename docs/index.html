What the result means

The two polarities concern distinct propositions in the same case. A supported correction does not erase counterevidence against the original claim. The full native knowledge_verdict remains null and authority_transferred remains false.

The public memory/WAL adapter is new integration code, separate from the full KnowledgeVault. The original FFI write call remains no-write CompatibilityHold; a new helper borrows unchanged bytes while the receiving owner recomputes and validates before persistence.

A coherent valid older history is accepted. The engine has finite checkpoint bounds; full replay costs are unbenchmarked, changing bound source bytes can invalidate records, and no migration or physical power-cut guarantee is established. Read the claim boundary.

Regression tests exposed floating-point JSON round-trip loss and storage effects before invalid-input rejection. The resulting parsing and CLI ordering fixes remain documented with their regression checks.
